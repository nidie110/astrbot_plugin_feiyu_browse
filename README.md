# astrbot_plugin_feiyu_browse

给 AstrBot 一个**只读**的浏览器：用你本机浏览器的真实登录态打开网页、读正文、截图，不点击、不填表、不动你的标签页。

## 人格设定里要写什么（装了之后必看）

这个插件**不直接提供给模型的工具**，它把自己的动作注册进
[`astrbot_plugin_persona_mind`](../astrbot_plugin_persona_mind) 的 `feiyu` 入口。所以：

1. **必须同时装 `persona_mind`。** 只装本插件时，模型那边一个动作都看不到 —— 不是坏了，是没有入口。
2. **人格设定里只写「什么时候该动手」，不要写 `feiyu(...)`、`action=`、`target=` 或任何参数名。**
   参数格式由插件在真要动手的那一轮临时告诉她（`engine/specs.py` + `engine/selector.py`），
   写进人格只会变成「同一件事两处说法」，而且插件启停时人格不会跟着变。
3. 人格里有这么几行，本插件才会被自然调用：

- 「你搜搜」「查查看」「这是谁」「什么梗」「多少钱」→ **搜**
- 给了文章链接 /「读一下这页」「正文写的什么」→ **读网页**
- 「截图」「这页长什么样」→ **截图**

### 可以直接粘贴的一段

只装本插件时，把下面这几行加进人格设定的末尾就够了：

```
- 「你搜搜」「查查看」「这是谁」「什么梗」「多少钱」「哪年」→ 先搜再答，别凭记忆编
- 「读一下这页」「这页写了什么」→ 打开念给他听
- 「截个图」「这页长什么样」→ 截给他看
```

**不要**改成 `feiyu(action="...")` 那种写法——参数格式由插件在真要动手的那一轮临时给她。

**反例**（这些不该触发）：裸的「说说」、「评论区」单独出现、她说「我去看看」但没给具体目标。

完整的原理、可逐字复制的人格段落、写入脚本，见 [persona_mind/README.md](../astrbot_plugin_persona_mind/README.md#让她自然地用这些本事人格设定里要写什么)。


## 怎么用

| 你这么说 | 她做什么 |
| --- | --- |
| 「你搜搜 XX」「XX 是谁」「什么梗」「多少钱」「哪年」 | 搜完把标题 / 来源 / 日期 / 链接一起给你，再自己说 |
| 「读一下这页」+ 链接 | 打开取正文，讲重点 |
| 「截个图」+ 链接 | 截图发回来 |
| 「这个地址能不能打开」 | 内网 / 本机地址一律拒，会直接说「这个地址我不会开」 |

**指令形式**：`/看网页 <url>`、`/网页截图 <url>`

**注意**：搜的是公开网页，需要配置 `search_key` 才能用；不配就只能读网页、截图。

## 特性

- **只读安全**：只做 `open / read / screenshot`，没有点击与输入，不会误触别人页面上的按钮
- **真实登录态**：复用已登录的浏览器实例，会员内容、需要登录的文档都能读
- **正文提取**：返回可读文本而不是一坨 HTML，默认截到 `max_chars` 字，省上下文
- **可选联网搜索**：填了 `search_key` 就能让模型用 `web_search`
- **自动识别链接**：群里有人甩链接，可以自动读一段摘要（可关）

## 安装

1. 装 [browser-skill](https://github.com/) 并确保 `bsk` 命令可用，或直接填 `bsk_path`
2. 目录放到 `astrbot/data/plugins/`，本插件无第三方依赖
3. WebUI 插件配置里填 `bsk_path`（可选）、`browser`（可选）
4. 重启 AstrBot

## 配置

| 键 | 说明 |
| --- | --- |
| `bsk_path` | `bsk.exe` 绝对路径；留空走 PATH |
| `browser` | 固定浏览器实例 id；留空自动取第一个在线实例 |
| `timeout` | 单次操作超时，默认 120 秒 |
| `max_chars` | 返回正文最大字数，默认 3000 |
| `search_key` / `search_api` | 联网搜索的 key 与地址，留空则关闭搜索工具 |

## 指令与工具

| 类型 | 名称 | 说明 |
| --- | --- | --- |
| 指令 | `/看网页 <url>` | 读正文 |
| 指令 | `/网页截图 <url>` | 截图发回 |
| 工具 | `read_webpage` / `screenshot_webpage` | 同上，给模型调用 |
| 工具 | `browse_open` / `browse_act` | 打开页面 / 有限交互（需谨慎） |
| 工具 | `web_search` | 需配置 `search_key` |

## 常见问题

**报找不到 bsk**
`bsk_path` 填错或没装。填绝对路径后重启插件。

**读了但内容为空**
页面是纯 JS 渲染且没等够时间，调大 `timeout`；或该页面需要登录而你的浏览器实例没登录。

## 联网搜索（1.2.0）

`web_search` 现在返回的是可核查的来源，而不是一堆摘要：

```
1. 标题（来源站 · 发布日期）
   https://...
   摘要（140 字）
```

- 带链接：模型看完可以直接 `read_webpage` 读全文，不用再猜
- `count` 参数 1-8，按需要给几条
- 同一关键词 10 分钟内命中缓存，不重复打接口
- 接口抖动自动重试一次；真不可用时直说「搜不动」，不会拿残缺结果糊弄

配置项：

| 键 | 说明 |
| --- | --- |
| `search_key` | 搜索接口的 key（DeepSeek 搜索工具），留空则关闭该工具 |
| `search_api` | 接口地址，默认 `https://api.deepseek.com/v1/tools/search` |
